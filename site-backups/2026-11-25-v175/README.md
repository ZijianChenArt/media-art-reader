# 媒体艺术档案 · 第 175 版公开备份

备份日期为 2026 年 11 月 25 日（北京时间）。界面来自 [媒体艺术档案](https://media-art-fieldnotes.mystic-dune-6472.chatgpt.site/) 已发布的第 175 版，对应 Sites 源码提交 `a4bafec5646c0bfde1fe59952928da4d5b252b6b`。

- `site/` 包含首页、作品档案、随机浏览、征集资讯的页面，以及样式、脚本、字体。
- `site/data/artworks.json` 包含 590 条作品的公开导出字段。页面保留完整的公开浏览内容、图片署名和来源链接。
- `site/latest.json` 保留该版资讯数据，包括 2 条雷达资讯和 15 条征集。
- 图片保留原站地址和来源链接，加载图片需要访问原站。外部页面和媒体保留原有链接。

备份应用了发布版的公开页面过滤规则，并排除了备份时数据库标记为已移除的条目。未发布资料、私有原始图像、账号选择与管理记录留在原系统。静态副本无需登录即可浏览，登录、云端保存和管理操作仍由原站提供。第三方素材的署名与权利说明随备份保留。

在本备份目录启动本地预览：

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory site
```

打开 [首页](http://127.0.0.1:8000/)、[作品档案](http://127.0.0.1:8000/archive/) 或 [随机浏览](http://127.0.0.1:8000/random/)。
