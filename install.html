三个尺寸Three sizes.

关于字体：大数字在 iPhone 上用的是系统自带的 Didot 斜体，网页这边用 Bodoni Moda 斜体作等价呈现，两者形态非常接近。标签与数据一律等宽，标题用系统无衬线——和本站的分层一致。
关于颜色：整块组件只有分类圆点和日期带色，展览征集红 / 驻留蓝 / 学术会议绿，其余是纸白、墨黑与灰。组件本体不加底纹，纯纸白——桌面壁纸各不相同，底纹只会变脏。

[02]

安装Install.

下载组件脚本
  1. 在 Scriptable 中新建脚本，把下载文件里的代码完整粘贴进去，运行一次确认能取到数据。
  2. 长按 iPhone 主屏幕 → 加号 → 选择 Scriptable → 挑尺寸（小 / 中 / 大）添加。
  3. 长按刚添加的组件 → 编辑小组件 → Script 选择刚保存的那个脚本。
  4. 中号与大号点击每一行会打开对应机会的官方页面；小号点击打开本站。
已经装过旧版？把新代码完整替换进原来的 Scriptable 脚本，保留脚本名称，保存并运行一次即可。桌面上的三个尺寸共用同一份脚本，不需要分别替换。
更新节奏：内容每周更新，脚本不需要每周重新下载；只有样式改版时才需要替换。刷新时机由 iOS 决定，脚本声明的是 60 分钟。
数据来源：脚本直接读取本站公开的 latest.json，仅在本机保存一份缓存。截止时区与提前关闭条件以本站详情和官方页面为准。
