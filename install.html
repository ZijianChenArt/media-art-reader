四个尺寸Four sizes.

与主页同一套规则。日期默认墨黑，14 天内截止才变红；分类色（展览征集红 / 驻留蓝 / 学术会议绿）只上在分类标签和右下角的关键数字上。整块组件不叠点阵，纯纸白——桌面壁纸各不相同，底纹只会变脏。

关于形状。卡片用主页同一个异形圆角。iOS 组件不支持四角不等圆，所以脚本用 DrawContext 把卡片画成一张背景图，尺寸按机型固定；遇到表里没有的机型会取最接近的一档，小屏机型（如 iPhone SE）会少显示一行，而不是溢出。

关于超大尺寸。Mac 与 iPad 才有。五个机会各占一格、第六格是刊头，按截止日期从近到远读；每个机会只留分类色标签、地点、短标题、日期与倒计时、关键数字。机会超过五个时，刊头格会写「另有 n 项」。我没能核实 Mac 超大组件的官方点数，所以脚本按保守面积排版（大屏 700×340，小 iPad 640×304），网格居中；设备真实面积更大时，多出来的只是留白，不会溢出。如果你在 Mac 上看到偏差，把 Scriptable 里 Device.screenSize() 的输出告诉我，我按实际尺寸调。

关于字体。日期与英文强调在 iPhone 上用系统自带的 Didot 斜体，网页用 Bodoni Moda 斜体，两者形态接近但不完全相同——这页预览显示的是 Bodoni，真机是 Didot。标签与数据一律等宽，标题用系统无衬线，分层与主页一致。

[03]

步骤Steps.

  1. 在 Scriptable 中新建脚本，把下载文件里的代码完整粘贴进去，运行一次确认能取到数据。
  2. 长按 iPhone 主屏幕 → 加号 → 选择 Scriptable → 挑尺寸（小 / 中 / 大）添加。在 Mac 或 iPad 上添加 Scriptable 小组件时可以选「超大」，脚本相同。
  3. 长按刚添加的组件 → 编辑小组件 → Script 选择刚保存的那个脚本。
  4. 中号、大号和超大号点击每个机会会打开对应的官方页面；小号点击打开本站。

已经装过旧版？把新代码完整替换进原来的 Scriptable 脚本，保留脚本名称，保存并运行一次即可。桌面上的四个尺寸共用同一份脚本，不需要分别替换。新版会读取 latest.json 里新增的 highlight 与 project_when 两个字段；旧数据缺这两项时会自动跳过，不会报错。

更新节奏。内容每周更新，脚本不需要每周重新下载，只有样式改版时才需要替换。刷新时机由 iOS 决定，脚本声明的是 60 分钟。

数据来源。脚本直接读取本站公开的 latest.json，仅在本机保存一份缓存。截止时区与提前关闭条件以本站详情和官方页面为准。
